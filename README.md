# 🏥 Hospital Management System

A full-stack Hospital Management System built using **HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB**. This application allows users to manage hospital records through a simple and responsive interface.

---

## 🚀 Features

- Add new patient records
- View all patient records
- Update patient details
- Delete patient records
- Responsive user interface
- MongoDB database integration
- RESTful API using Express.js

---

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## 📦 Required Packages

Install the following packages before running the project.

### Initialize Project

```bash
npm init -y
```

### Install Dependencies

```bash
npm install express mongoose cors
```

### 5. Start the Project

Using Node

```bash
node server.js
```
